----- Sistema de Mercado com Preço Dinâmico -----

Grupo 02 : Elisa B. Kappaun, João Cordebello, Lucas Cardoso, Maicon Muniz, Paola Pinheiro.

>> Introdução
>> 
Você foi contratado como desenvolvedor de banco de dados de um supermercado moderno que quer
modernizar sua gestão de preços. Em vez de preços fixos, o mercado adota uma estratégia de preço
dinâmico: os valores dos produtos mudam conforme a demanda, o estoque disponível e as condições
do mercado.
